# HEROKU — Новая орбита

Motion-design трейлер проекта [Heroku](https://github.com/Heroku-userbot/Heroku).

[Скачать видео в 4K](https://github.com/m4pbuh/Test/raw/refs/heads/main/Heroku_New_Orbit_4K.mp4)

- Разрешение: 3840 × 2160
- Длительность: 36 секунд
- Частота кадров: 24 fps
- Формат: MP4, H.264 + AAC, стерео
- Размер: 36 900 212 байт

Шесть анимированных сцен, оригинальная музыкальная дорожка и циклический переход между финалом и началом. Интерфейсы показаны как художественная визуализация возможностей.

Оригинальная символика Heroku взята из репозитория проекта; права принадлежат её авторам.
